markdown# ejercicios-pseint-logica
Mi ruta aprendiendo lógica de programación con PSeInt desde cero.

## Qué hay aquí?
- 🎵 Mi_lista_de_reproduccion.psc - Playlist con arreglos 100% desde cero (Bachata, Safaera, Pepas)
- 🛒 Tienda_China.psc - Sistema de tienda con facturación
- 🏧 Cajero_Automatico.psc - Simulación de cajero con menú y validación de saldo
- 🫓 PUPUSAS_MAMI_CHU.psc - Sistema de pupusería con menú, contadores y resumen de pedido

## Qué aprendí hoy
Hoy toqué lo más importante de los bucles:

- **Repetir Hasta Que:** Aprendí a hacer menús que no se cierran hasta que el usuario decida salir.
- **El operador lógico `O`:** Para salir del bucle con dos opciones diferentes (`Hasta Que menu=5 O menu=6`). Con esto evité que el menú se repitiera después de finalizar el pedido.
- **Según (Switch):** Para manejar las opciones del menú de forma limpia.
- **Contadores y Acumuladores:** En la pupusería usé variables como `cRevuelta, cQueso, totalPupusas, Total` para guardar cuántas pupusas pidió de cada tipo y al final mostrar el resumen completo con el total a pagar.
- **Manejo de flujo:** Cómo no mostrar de nuevo el menú cuando ya finalizó la ejecución (Ejecución Finalizada).
